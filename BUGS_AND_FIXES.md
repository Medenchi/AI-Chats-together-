# BUGS_AND_FIXES.md

# 🐛 AI-Chats-Together — Найденные ошибки и исправления

## 🔴 КРИТИЧЕСКИЕ ОШИБКИ (ломают работу) — ВСЕ ИСПРАВЛЕНЫ

### ❌ BUG #1: Дублирующийся обработчик `/start` — deeplink НИКОГДА не сработает
**Файл:** `bots/master.py`  
**Исправление:** Объединён в ОДИН `CommandStart()` с проверкой аргументов.

### ❌ BUG #2: Полностью неправильный поток Managed Bots API
**Файл:** `bots/master.py`  
Код вызывал `getManagedBotToken` ДО подтверждения пользователя.  
**Исправление:** Добавлен `process_managed_bot_update()` + правильная последовательность.

### ❌ BUG #3: Неправильный формат deep link
**Исправление:** `https://t.me/newbot/{manager}/{username}?name={name}` (формат API 9.6)

### ❌ BUG #4: Нет обработчика `managed_bot` update
**Исправление:** Добавлен `allowed_updates=["message", "callback_query", "managed_bot"]`

### ❌ BUG #5: `get_all_characters(active_only=True)` — **КАРАУЛ! TypeError при старте**
**Исправление:** Параметр называется `active`, не `active_only`

### ❌ BUG #6: `DEFAULT_REPLY_CHANCE` не передаётся в конфиг
**Исправление:** Добавлен в `build_config()`

## 🟡 ОШИБКИ БЕЗОПАСНОСТИ — ИСПРАВЛЕНЫ

### ⚠️ BUG #7: `eval()` на данных из БД
**Исправление:** `ast.literal_eval()` + `json.loads()` через `PersonalityGenerator.parse_personality_string()`

### ⚠️ BUG #8: **ЛЮБОЙ человек мог создавать ботов**
**Исправление:** Добавлена проверка `ADMIN_USER_IDS` — только указанные ID могут управлять ботами.  
Если `ADMIN_USER_IDS` не задан — доступ открыт всем (обратная совместимость).

## 🟡 ЛОГИЧЕСКИЕ ОШИБКИ — ИСПРАВЛЕНЫ

### BUG #9: ВСЕ боты отвечают на одно сообщение (3-5 ответов)
**Исправление:** Максимум 2 бота, с рандомной выборкой

### BUG #10: Markdown не экранировался
**Исправление:** `escape_markdown()` + переход на `MarkdownV2`

### BUG #11: Сессии CharacterBot не закрывались
**Исправление:** `await self.bot.session.close()` в `CharacterBot.stop()`

### BUG #12: Personality хранился как Python repr
**Исправление:** `json.dumps()` / `json.loads()`

## ✨ НОВОЕ

### Альтернативный метод ввода токена
Кнопка **«🔑 Ввести токен бота вручную»**:
1. Пользователь создаёт бота через @BotFather
2. Копирует токен → отправляет в чат
3. Бот валидирует → подключает → создаёт топик

### Система прав доступа (ADMIN_USER_IDS)
- В `.env` добавлена переменная `ADMIN_USER_IDS=123,456`
- Только админы могут: создавать персонажей, вводить токены, управлять ботами
- Остальные видят только список и статус
- Если не задано — доступ открыт всем
