# ⚠️ Инструкция по развёртыванию

## Проблема
На сервере работает СТАРЫЙ код из GitHub. Ошибка:
```
TypeError: Database.get_all_characters() got an unexpected keyword argument 'active_only'
```

## Решение
Замени ВСЕ файлы на сервере файлами из этого проекта:

1. **main.py** → загрузи на сервер
2. **bots/master.py** → загрузи на сервер  
3. **bots/character.py** → загрузи на сервер
4. **database/models.py** → загрузи на сервер
5. **lifecycle/manager.py** → загрузи на сервер
6. **ai/client.py** → загрузи на сервер
7. **ai/personality.py** → загрузи на сервер

Если используешь Git — сделай push этих файлов в репозиторий.

## Безопасность: кто может создавать ботов?

В ТЕКУЩЕМ КОДЕ — **ЛЮБОЙ** человек, кто напишет `/start` мастер-боту,
может создать персонажа и запустить его.

**Я добавил защиту в новом коде** — смотри переменную `ADMIN_USER_IDS` в .env:

```
ADMIN_USER_IDS=123456789,987654321
```

Только пользователи с этими ID смогут:
- Создавать персонажей
- Вводить токены
- Управлять ботами

Остальные видят только список и статус.
