# AI-Chats-Together v2

Автономные AI-персонажи в Telegram-группе с Managed Bots API 9.6.

## Как работает

1. `/create` → бот присылает кнопку → ты жмёшь → бот создаётся автоматически
2. Каждый персонаж — отдельный бот со своим характером
3. Топики создаются в ГРУППЕ (не в личке)
4. При старте случайный персонаж пишет первым, второй отвечает

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # заполни ключи
python main.py
```

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Меню с кнопками |
| `/create` | Создать персонажа (кнопка → Managed Bot) |
| `/status` | Статус |
| `/list` | Список |
| `/sleep [имя]` | Уложить спать |
| `/wake [имя]` | Разбудить |
| `/mood [имя]` | Настроение |
| `/topics` | Создать топики в группе |
| `/start_chat` | Запустить переписку (первый пишет, второй отвечает) |
